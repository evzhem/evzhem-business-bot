# 🤖 evzhem_business_bot — Telegram Business Userbot & Automation Service

Продвинутый сервис автоматизации личных чатов Telegram на базе официального **Telegram Business API (Bot API 7.2+)** с интерактивным **Telegram Mini App (Web App)** дашбордом, покадровыми живыми анимациями, защитой от лимитов (FloodWait), автоответчиком, системой мутов в ЛС и монетизацией через Telegram Stars.

---

## 🌟 Ключевые возможности

1. **💫 Студия покадровых анимаций в ЛС:**
   - Превращение точечных команд в живые трансформеры: `.люблю`, `.сердце`, `.сладких снов`, `.доброе утро`, `.иди нахуй` (трансформация в розу), `.пиздец` (падающие слезы), `.загрузка`, `.матрица`, `.18+`, `.ты`, `.писюн`.
   - **Эффект пишущей машинки:** `.печать [текст]` — посимвольный набор с живым курсором.
   - **Smart Adaptive Rate Limiter:** адаптивные задержки (0.35-0.5с), предотвращающие ошибки 429 FloodWait.
   - **Конструктор кастомных анимаций:** создание собственных команд прямо из WebApp дашборда.

2. **🔇 Приватность и тихий мут:**
   - `.мут` / `.мут 15м` — моментальное тихое удаление всех входящих сообщений от токсичного собеседника.
   - `.антимут` — белый список избранных контактов.
   - `.самоуничтожение [секунды]` — автоматическое удаление исходящих сообщений по таймеру.
   - `.спам 'текст' [кол-во]` — контролируемый безопасный спам (макс. 30).

3. **🤖 Smart Автоответчик (3 режима):**
   - **Простой текст:** авто-шаблон для занятости.
   - **Ночной режим / Расписание:** автоматическая активация в заданные часы (например, с 23:00 до 08:00).
   - **Ключевые слова:** ответы по совпадению триггеров ("цена", "где ты", "реквизиты").
   - **AI-режим:** интеллектуальные ответы через OpenAI GPT-4o / Claude.
   - **Умный кулдаун:** защита от спама (не чаще 1 раза в час на диалог).

4. **📊 Аналитика переписки:**
   - `.наша стата` — отправка графической карточки диалога: соотношение сообщений, кто пишет чаще, баланс активности, S/A/B/C ранг связи.
   - Глобальная статистика в WebApp.

5. **📱 Telegram Mini App (TMA):**
   - Полноценный SPA интерфейс внутри Telegram: дашборд, живой чат-симулятор, редактор автоответчика, управление мутами, статистика и система достижений.

6. **⭐ Монетизация & Telegram Stars:**
   - Встроенная оплата подписок за Telegram Stars (XTR) в один клик.

## 🚀 Быстрый старт

### 1. Требования
- Python 3.11+
- Токен бота от `@BotFather`
- Подписка Telegram Premium у владельца аккаунта

### 2. Установка зависимостей
```bash
git clone <repo>
cd telegram_business_bot
pip install -r requirements.txt
```

### 3. Настройка конфигурации
Скопируйте пример конфига:
```bash
cp .env.example .env
```
Укажите в `.env` ваш `BOT_TOKEN` и `BOT_USERNAME`.

### 4. Запуск бэкенда и бота
```bash
# Запуск WebApp API сервера (порт 8000)
uvicorn webapp.backend.app:app --host 0.0.0.0 --port 8000

# В отдельном терминале: запуск бота
python -m bot.main
```

### 5. Запуск через Docker Compose (Production)
```bash
docker-compose up -d --build
```

## 📱 Как подключить бота к Telegram Business

1. Откройте Telegram на телефоне.
2. Перейдите в **Настройки ➔ Telegram Business ➔ Чат-боты** (или *«Автоматизация чатов»*).
3. Введите юзернейм вашего бота: `@YourBotUsername`.
4. Нажмите **«Добавить»** и выдайте все 5 прав:
   - ✅ Чтение сообщений
   - ✅ Ответы на сообщения
   - ✅ Отметки о прочтении
   - ✅ Удаление исходящих
   - ✅ Удаление входящих
5. Откройте любой личный диалог с другом и напишите `.люблю` или `.печать Привет!`.
